Jak to działa

Każdy komponent ma obok siebie mały kontener *-updater (w spoczynku ~1 MB RAM, bez sieci). Tylko on ma dostęp do Dockera — panel i bramka nie.
Obrazy z rejestru (DEPLOYRA_IMAGES=ghcr.io/…/deployra w deploy/.env): docker compose pull + up -d, zwykle kilkanaście sekund.
Ze źródeł (domyślnie): git przewija repozytorium do taga vX.Y.Z i przebudowuje obrazy — wolniej, ale bez rejestru.
Proxmox bez Dockera: install-native.sh --update uruchamiany przez systemd-run.
